# GitTune Privacy Policy

**Last Updated: October 7, 2026**

GitTune (hereinafter referred to as "the App") is a Windows desktop application designed for viewing and managing global Git configurations. This Privacy Policy outlines how GitTune accesses, uses, stores, and processes user-related information.

## 1. Information We Access

GitTune may access information that users have actively set within their local Git configurations, including but not limited to:

- Git username (`user.name`)
- Git email address (`user.email`)
- Git default branch settings
- Git GPG signing configurations
- Git send-email configurations

This information is configured by users directly on their devices.

## 2. How Information Is Used

GitTune accesses the aforementioned information solely to provide the App's core functions, such as:

- Displaying current Git configurations;
- Editing global Git configurations;
- Helping users manage Git identity information;
- Configuring Git signing and other Git-related settings.

GitTune does not use this information for advertising, user profiling, or any purposes unrelated to the App's core functionality.

## 3. Information Storage and Transmission

GitTune is a local desktop application.

In the current version, GitTune does not upload the aforementioned Git configuration information to servers operated by the GitTune developers, nor does it sell, rent, or provide this information to third parties for their own use.

Modifications made to Git configurations via GitTune are written directly to the Git configuration files on the user's device, in accordance with user actions.

Apart from Git itself and other system components configured by the user, GitTune does not establish any backend data storage for uploading the aforementioned personal information.

## 4. Third-Party Disclosure

In the current version, GitTune does not proactively disclose users' Git identity information or other information accessed via Git configurations to third parties.

If future versions introduce new features that access, collect, or transmit personal information, we will update this Privacy Policy prior to the launch of such features and, where applicable, provide appropriate user choice and control mechanisms. 

## 5. User Control

Users may view and modify their Git configuration via GitTune at any time, or manage relevant configurations directly using Git or tools provided by their operating system.

GitTune does not prevent users from accessing, modifying, or deleting their local Git configuration.

## 6. Data Security

As GitTune does not currently transmit the aforementioned information to servers operated by the developer, no such information is stored on GitTune servers.

Users should continue to properly safeguard their devices, Git configurations, GPG keys, and other sensitive settings, and implement appropriate security measures based on their own needs.

## 7. Children's Privacy

GitTune is not designed to collect personal information from children, nor does it proactively collect personal information unrelated to its core functionality.

## 8. Changes to the Privacy Policy

We may update this Privacy Policy if there are changes to GitTune's functionality or data processing practices.

Updated versions of the Privacy Policy will be posted on this page, and the "Last Updated" date will be revised accordingly.

## 9. Contact Us

If you have questions regarding this Privacy Policy or GitTune's privacy practices, please contact us via the GitTune project's public support channels.
